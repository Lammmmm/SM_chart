# 聪明钱名单批次分析

## 最重要的数据边界

- 原始历史文件 smart_money_cache.json 永远只读，不删除、不改写，也不需要重新抓取。
- 现有约 95 天历史数据会自动重新划分名单批次，只用于开发和探索性回测。
- 模型冻结时间固定在 2026-08-27T01:42:59Z。只有此后新采集的数据才属于真正的样本外验证。
- 币安抓取和本地缓存逻辑保持原样；所有新结果写入 data/derived/。

## 一条命令完成全部分析

中文命令：

    python smart_money_analysis.py 处理聪明钱

兼容原技术命令：

    python smart_money_analysis.py process-smart-money

以上命令会依次完成：

1. 原始记录质量检查。
2. 自动识别名单批次刷新。
3. 等待名单稳定并建立中位数基准。
4. 计算同一批次内的仓位变化和净风险流。
5. 识别已有亏损与新亏损。
6. 跟踪亏损后的加仓、持仓、减仓和恢复盈利。
7. 计算未来 1、4、12、24 小时比特币收益。
8. 输出总体和分组回测。
9. 生成中文分析报告。

仅查看已有中文报告：

    python smart_money_analysis.py 查看聪明钱报告

## 推荐直接阅读的中文文件

- 聪明钱分析报告_中文.md：最易阅读的完整摘要和回测结果。
- 聪明钱回测结果_中文.csv：中文表头的总体及分组回测。
- 聪明钱逐条分析_中文.parquet：中文列名的逐条分析结果。
- 聪明钱事件表_中文.parquet：中文列名的新亏损事件表。
- 聪明钱批次表_中文.parquet：中文列名的名单批次表。

原有英文文件是程序使用的兼容格式，可以不看。

## 测试

当前 Python 环境有一个与本项目无关的第三方测试插件版本冲突，因此运行测试时需要关闭全局插件自动加载：

    $env:PYTEST_DISABLE_PLUGIN_AUTOLOAD='1'
    python -m pytest tests/test_smart_money_analysis.py -q

所有阈值都集中在 smart_money_analysis_config.json，并附有中文解释。禁止使用未来样本外数据反复调参后仍声称结果是样本外验证。
